الحسابات العابرة للأجهزة تتطلب خدمة خلفية آمنة عبر HTTPS وقاعدة بيانات، مع أسماء مستخدمين فريدة وكلمات مرور مجزأة Argon2id أو scrypt، حماية من التخمين، إدارة جلسات آمنة، وسياسة تعارض عند دمج التقدم. لا تخزن كلمات المرور في localStorage ولا في GitHub Pages. قبل الإطلاق يجب توفير استضافة API، قاعدة بيانات، أسرار الخادم، وفحص أمني واختبار عبر جهازين. النسخ الاحتياطي JSON متاح الآن كبديل مؤقت.
