تحديث الأكاديمية الألمانية الموحّد V83 إلى V90
================================================
هذا الملف يجمع كل تعديلات الموقع من V83 إلى V90 في تثبيت واحد.

المتطلبات:
- موقعك يحتوي بالفعل على V82 أو أحد الإصدارات V83 إلى V89.
- لا يصلح هذا التحديث وحده لترقية نسخة أقدم من V82.

التركيب باستخدام GitHub Desktop:
1) فك ضغط ملف ZIP.
2) افتح مستودع german في GitHub Desktop، ثم Repository > Show in Explorer.
3) انسخ فقط ملفات JavaScript السبعة من الحزمة إلى مجلد german الأساسي.
4) اختر Replace / استبدال لكل الملفات المتطابقة.
5) ارجع إلى GitHub Desktop، واكتب German Academy V90 Combined في Summary.
6) اضغط Commit to main ثم Push origin.
7) افتح الموقع وحدّث الصفحة تحديثاً قوياً (Ctrl+Shift+R). على الهاتف يمكن فتح نافذة خاصة جديدة.

الملفات التي تستبدلها:
app.js
lessons.js
lessons-advanced.js
review.js
exam-review.js
conjugation.js
sw.js

ملاحظات:
- لا تنسخ ملفات هذه الحزمة إلى Cloudflare ولا تغيّر قاعدة بيانات D1.
- هذه الحزمة لا تتضمن تعديلات على HTML أو ملفات حسابات Cloudflare.
- تم الحفاظ على نظام الأقفال وترتيب المراحل في نسخ المصدر التي جُمعت منها الملفات.
- لا تحذف المجلد أو أي ملفات أخرى من مستودعك.
- لا تُرفع الوثيقتان TXT؛ هما للشرح فقط.
- لا تحتاج إلى تثبيت تحديثات V83 وV84 ... V89 على حدة.
