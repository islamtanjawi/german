V102 — إصلاح الانتقال إلى الدرس على الكمبيوتر

الملفات: lessons.js و lessons.html و sw.js فقط.

1. فك الضغط وانسخ الملفات الثلاثة إلى جذر مجلد موقع german، واستبدل القديمة.
2. في GitHub Desktop: Changes > Summary: V102 desktop lesson scroll > Commit to main > Push origin.
3. انتظر ظهور التحديث في GitHub Pages ثم افتح lessons.html?v=102 على الكمبيوتر.
4. اضغط Ctrl+Shift+R وجرب درساً مفتوحاً من وسط قائمة الدروس.

الإصلاح يستعمل window.scrollTo محسوباً من موقع لوحة الشرح، دون شرط على عرض الشاشة. كما أضفنا رقم إصدار لرابط JavaScript لضمان إعادة تنزيله.
لم نعدل بيانات الحسابات، قاعدة البيانات، الأقفال أو التقدم.

ملاحظة: فُحصت صياغة الملفات برمجياً لكن الاختبار داخل متصفح المستخدم بعد النشر لا يزال مطلوباً.
