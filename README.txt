مدرّبي الألماني — نسخة تطوير شخصية

الملفات:
- index.html: بنية الموقع
- style.css: التصميم المتجاوب والوضع الداكن
- app.js: التفاعل والاختبارات وحفظ التقدم والمراجعة
- data.js و data-m3.js: قاعدة المفردات والجمل الأصلية

طريقة الاستخدام:
1. ارفع جميع الملفات الخمسة إلى مجلد الموقع نفسه في GitHub Pages.
2. افتح الموقع من المتصفح.
3. اختر المستوى ثم اليوم.
4. علّم الكلمات التي أتقنتها، واستخدم تبويب «اختبر نفسك».
5. الكلمات التي تخطئ فيها تظهر في «مراجعة الأخطاء».

الحفظ:
- يحافظ الموقع على مفتاح التقدم القديم deutsch-progress-v1 حتى لا تضيع الكلمات التي سبق تحديدها.
- تُحفظ بيانات الاختبارات والمراجعة في deutsch-coach-v2 داخل LocalStorage في المتصفح نفسه.
- مسح بيانات المتصفح أو استخدام جهاز/متصفح آخر قد يؤدي إلى فقدان التقدم؛ لا توجد مزامنة سحابية حالياً.

ملاحظة تعليمية:
الاختبار الحالي يراجع معنى المفردة من الألمانية إلى العربية. يمكن تطويره لاحقاً ليشمل اختيار الكلمة الألمانية، كتابة الإجابة، تصريف الأفعال، وأدوات التعريف والجمع.
